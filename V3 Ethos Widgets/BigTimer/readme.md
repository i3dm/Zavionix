# Zavionix BigTimer

Large flight timer display for FrSky radios running Ethos.

BigTimer puts a selected Ethos model timer at the center of a clear, large display, making elapsed or remaining flight time easy to read at a glance.

## What it does

- Displays the selected model timer in large digits.
- Includes receiver signal strength and up to two receiver battery readings.
- Combines the timer with model information and transmitter status.

## Setup

Configure the timer's behavior in the Ethos model settings, then select that timer in BigTimer. Assign the receiver telemetry sources and choose the appropriate stick mode.

Copy the complete `BigTimer` folder to the radio's `scripts` folder, add the widget to a screen, and open **Configure Widget** to select your sources and settings. Use a full-screen layout.

See the [V3 widget installation instructions](../readme.md#installation) for more details. Displayed readings depend on the telemetry provided by your model.
